# Simple Interest Calculator

A simple Bash script to calculate simple interest based on user inputs.

## Description
This project contains a script that calculates simple interest given the principal amount, annual interest rate, and time period in years.

## Input Fields
- **Principal Amount**: The initial sum of money.
- **Rate of Interest**: The annual percentage rate.
- **Time Period**: The duration in years.

## Output
- **Simple Interest**: The calculated interest amount.
